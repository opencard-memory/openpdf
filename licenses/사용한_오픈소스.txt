사용한 오픈소스
=================

OpenPDF Office는 아래 오픈소스 소프트웨어를 사용합니다.
설치 전 각 프로젝트의 라이선스와 고지 의무를 확인해 주세요.

1. PoDoFo
   용도: PDF 파싱, 콘텐츠 수정, 이미지 객체 처리, 증분 저장, PDF 전자서명
   라이선스 선택: Mozilla Public License 2.0
   프로젝트: https://github.com/podofo/podofo
   주의: PoDoFo 도구는 GPL 2.0 이상이므로 제품에는 도구 실행 파일을 포함하지 않고 라이브러리만 동적 연결합니다.

2. QPDF
   용도: PDF 구조 검사, 페이지 조작, 암호화, 복구
   라이선스: Apache License 2.0
   프로젝트: https://github.com/qpdf/qpdf

3. PDFium
   용도: PDF 렌더링과 화면 표시
   라이선스: BSD 3-Clause 및 포함된 제3자 구성요소 라이선스
   프로젝트: https://pdfium.googlesource.com/pdfium/

4. Tesseract OCR
   용도: 스캔 문서 문자 인식
   라이선스: Apache License 2.0
   프로젝트: https://github.com/tesseract-ocr/tesseract

5. Leptonica
   용도: OCR 이미지 전처리
   라이선스: BSD 2-Clause
   프로젝트: http://www.leptonica.org/

6. OpenSSL 3.x
   용도: CMS/PKCS#7 서명과 인증서 처리
   라이선스: Apache License 2.0
   프로젝트: https://www.openssl.org/

7. Qt 6
   용도: Windows 사용자 인터페이스와 기본 PDF 보기
   라이선스: 사용 모듈에 따른 LGPLv3/GPLv3 또는 상용 라이선스
   프로젝트: https://www.qt.io/

8. Inno Setup
   용도: Windows 설치 프로그램 제작
   라이선스: Inno Setup License
   프로젝트: https://jrsoftware.org/isinfo.php

중요
----
이 요약은 원문 라이선스를 대체하지 않습니다. 출시 빌드에는 사용한 정확한 버전의 LICENSE,
NOTICE, 저작권 고지와 SBOM을 포함해야 합니다. MPL 2.0으로 사용한 PoDoFo 파일을 수정한 경우,
수정된 해당 파일의 소스를 MPL 2.0 조건에 따라 제공해야 합니다. Qt LGPL 배포를 선택하면
동적 연결, 재연결 가능성, 라이선스와 해당 소스 입수 방법 등 LGPL 의무를 별도로 충족해야 합니다.

9. Google Fonts 글꼴 모음
   용도: 오프라인 글꼴 대체 및 편집용 임베딩 글꼴
   라이선스: 각 글꼴 폴더에 포함된 OFL, Apache 또는 UFL 원문
   주의: 각 글꼴 파일과 함께 해당 라이선스 원문을 설치합니다.
